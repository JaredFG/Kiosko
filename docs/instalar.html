Instalar la app

Para tablets Android 5.1 o superior

Descargar Kiosco.apk Debe pesar 31.6 MB
  1. Toca el botón y espera a que termine la descarga. Revisa que el tamaño sea 31.6 MB.
  2. Abre el archivo descargado desde Descargas.
  3. Si la tablet lo pide, activa Orígenes desconocidos (Ajustes → Seguridad) y vuelve a abrir el archivo.
  4. Toca Instalar y después Abrir.
Si ya había un Kiosco instalado, desinstálalo antes. Si sale "Error al analizar el paquete", borra las descargas anteriores de Kiosco y descarga de nuevo desde aquí.
